## The Aircraft

The [Stoddard-Hamilton Glastar](https://www.stoddard-hamilton.com/) is an all-metal, two-seat kit aircraft known for its excellent handling and versatility. Kit #5445 is being built to the following specification:

| Component | Specification |
|---|---|
| Engine | Lycoming O-320-D series (160hp, high compression) |
| Fuel & Ignition | SDS EFI & Electronic Ignition (no carb, no mags) |
| Sump | Superior Air Parts cold sump |
| Exhaust | Vetterman Trombone |
| Primary Alternator | 60A belt-driven |
| Backup Generator | Monkworks 30A (vacuum pad) |
| Batteries | 2× EarthX LiFePO4 |
| Electrical Architecture | Z-14 dual-bus |
| Propeller | Catto 3-blade ground-adjustable whisper prop (nickel leading edges) |
| Undercarriage | Tricycle gear |

The SDS EFI/EI combination with all-electric ignition and Z-14 dual-bus makes for a very light, reliable powertrain with robust redundancy.
